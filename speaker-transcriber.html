Models are fetched from the Hugging Face Hub and cached by your browser. Any Whisper ONNX repo that works with Transformers.js can be typed above. The embeddings field is a comma-separated list tried in order; each id is first looked up under the self-hosted URL, then on the Hub (gated, private or missing repos are skipped). Runs entirely client-side with Transformers.js (ONNX Runtime Web). Speech recognition: OpenAI Whisper. Speaker segmentation: pyannote/segmentation-3.0. Voice embeddings: WeSpeaker ResNet34. First run downloads the models (tens to hundreds of MB); later runs use the browser cache.
