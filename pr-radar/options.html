PR Radar settings

GitHub token

Stored only in this browser profile (chrome.storage.local). Read-only use needs a classic token with repo, or a fine-grained one with Pull requests, Issues, Checks and Metadata read on your repos. The action buttons also need Pull requests + Issues write, and Actions write for re-running a job.

Config (JSON)

Queries, labels, checks, extractors and actions. Field reference: the comments on DEFAULT_CONFIG in lib.js, or the README.
