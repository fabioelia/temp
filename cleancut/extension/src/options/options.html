CleanCut

Watch any show at the rating you choose. CleanCut skips, mutes or blurs scenes using timestamps tagged by the community (reviewed on GitHub) and a scan-ahead analysis of the episode's subtitles.

Community data

Tags and skip lists are reviewed files in a public GitHub repository, published as static pages. CleanCut downloads a small index, then only the files for titles you watch. Nothing about you is sent.

Your tags

Tags you make apply for you right away. To share one with everyone, submit it: CleanCut opens a ready-made pull request on GitHub (no git needed), and once it's reviewed it's published for all.

    How to tag

    While watching, press Alt+[ when a scene starts and Alt+] when it ends, then pick a category and severity. Tags apply right away for you. Submit them from Your tags above to share with everyone.

    Scan-ahead works best with English subtitles available. On Netflix and Prime, CleanCut reads the track the player already downloads. Turn on English [CC] once if nothing gets scanned.
