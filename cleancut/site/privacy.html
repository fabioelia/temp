Privacy policy

Last updated: [[DATE]]

CleanCut is a browser extension. This page explains exactly what data it handles. The short version: it works from files it downloads and from your own device, and sends nothing about you to us. We don't sell data, show ads, or build profiles.

What stays on your device

  • Subtitles. The extension reads the subtitle file the video player downloads and analyzes it locally. Subtitle text is never sent to us or anyone else.
  • Your settings (chosen rating, per-category choices, actions). These live in the browser's extension storage. If you're signed in to Chrome with sync turned on, the browser may sync them across your devices as it does for any extension.
  • Your own tags and a cache of recently looked-up community data are stored locally in the extension.

What the extension downloads, and from where

Community tags and skip lists are public files in a GitHub repository, published on GitHub Pages. There is no CleanCut account and no CleanCut server that receives information about you.

  • The index. A small file listing which titles have community data. It is the same file for everyone and contains nothing about you. The extension checks it every few hours.
  • Title files. Only when the index says there is data for the title you're watching, the extension downloads that one file. This request tells GitHub (as host of the files) which title file was requested, along with your IP address and browser details that any web request includes. We don't see these requests. Titles without community data cause no request at all.
  • The extension never uploads the title you watch, your viewing history, your account on any streaming site, or subtitles.

If you choose to contribute

Sharing a tag or skip list is always your explicit action: CleanCut opens a GitHub page with a pre-filled file, and nothing is submitted until you propose it there. Contributions are public, including the title, timestamps, any note you write, and your GitHub username (GitHub's own policies cover your GitHub account). You can ask us to remove a contribution at any time (see Support).

Hosting logs

GitHub, as the host of GitHub Pages, may keep standard access logs under its own privacy statement. CleanCut itself runs no server and keeps no logs.

What we do not do

  • We don't sell or rent data, and we don't share it with advertisers or data brokers.
  • We don't use data for creditworthiness, lending, or any purpose unrelated to CleanCut's single purpose of filtering scenes.
  • We don't load or run remotely hosted code. All extension code ships inside the extension package.

Permissions the extension asks for

  • Access to netflix.com and primevideo.com / amazon video pages: to detect what's playing and to skip, mute or blur it.
  • storage: to save your settings and tags.
  • activeTab / scripting: so the popup can show and control the current tab's player.
  • Other sites: CleanCut works on another page only when you click its toolbar button there (activeTab).

Your choices

  • Uninstalling the extension removes everything stored on your device.
  • To remove something you contributed, open an issue or email us at the address below and we'll delete the file. (Git history keeps old versions; we can ask GitHub to purge personal data on request.)
  • You can turn the extension off at any time from its popup.

Children

CleanCut is designed to help families. It is operated for adults and doesn't knowingly collect personal information from children under 13. There are no accounts. Contributions are public on GitHub, so please don't include personal details in notes.

Changes

If this policy changes materially, we'll update the date above and note it in the extension's release notes.
